# Launch an RStudio addin to select options for read_ascii_setup()

Launch an RStudio addin to select options for read_ascii_setup().

## Usage

``` r
read_ascii_setup_addin()
```

## Value

read_ascii_setup() code to console with options based on user input

## Examples

``` r
if (interactive()) {
  read_ascii_setup_addin()
}
```
